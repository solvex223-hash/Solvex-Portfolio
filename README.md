# SolveX portfolio

Do NOT double-click index.html. This is a Vite project and must be served.

    npm install
    npm run dev        # opens http://localhost:3000

Production build (deploy the dist folder to Vercel, Netlify or any static host):

    npm run build
    npm run preview

If the page is blank, open the browser console (F12) and send the red error text.
